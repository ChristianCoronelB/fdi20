### Archivo de descarga
- **Archivo:** `fabrica-de-ideas-descarga.zip`
- **Tamaño:** ~654 KB
- **Fecha:** Abril 2026

### Cómo instalar

1. Descarga el archivo ZIP
2. Descomprime en tu servidor local
3. Ejecuta los siguientes comandos:

```bash
cd fabrica-de-ideas
bun install
bun run db:push
bun run dev
```
