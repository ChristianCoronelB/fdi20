===========================================
NOVEDADES v2.2.1
===========================================

1. CORRECCIÓN DEL ENUM ACTIVITYTYPE
   - Agregados tipos de actividad faltantes: CHARLA_MAGISTRAL, PITCH, CEREMONY
   - Corregido error de Prisma Studio al leer tabla Activity
   - Mejor manejo de errores en API de actividades
   - Selectores de tipo de actividad actualizados

2. MÓDULO DE EVALUACIÓN ACTIVO
   - Asignación de proyectos a evaluadores funcional
   - Formulario de evaluación con rúbrica de 6 criterios:
     * Innovación y Creatividad (20%)
     * Viabilidad del Negocio (15%)
     * Impacto Social/Ambiental (15%)
     * Pitch - Presentación y Comunicación (20%)
     * Potencial de Escalamiento (10%)
     * Entregable - Poster, PMV, Producto o Servicio (20%)
   - Búsqueda de proyectos en asignaciones
   - Comentarios por criterio y general
   - Puntaje total automático sobre 100 puntos

3. ESTABILIDAD GENERAL
   - Correcciones en el manejo de tipos de actividad
   - Mejoras en la gestión de errores de API

===========================================
INSTALACIÓN RÁPIDA
===========================================

1. Descomprime este archivo
2. Abre una terminal en la carpeta
3. Ejecuta: bun install
4. Ejecuta: bun run db:generate
5. Ejecuta: bun run db:push
6. Ejecuta: bun run db:seed
7. Ejecuta: bun run dev
8. Abre: http://localhost:3000
