===========================================
INSTALACIÓN EN SERVIDOR LOCAL
===========================================

1. Descomprime este archivo
2. Abre una terminal en la carpeta
3. Ejecuta: bun install
4. Ejecuta: bun run db:generate
5. Ejecuta: bun run db:push
6. Ejecuta: bun run db:seed
7. Ejecuta: bun run dev
8. Abre: http://localhost:3000

IMPORTANTE: Si tienes una base de datos existente con tipos
de actividad que no están en el enum, debes:

Opción A - Actualizar los datos existentes:
```sql
-- En Prisma Studio o SQLite CLI
UPDATE activities SET type = 'PRESENTATION' WHERE type = 'CHARLA_MAGISTRAL';
UPDATE activities SET type = 'PRESENTATION' WHERE type = 'PITCH';
UPDATE activities SET type = 'OTHER' WHERE type NOT IN (
  'KEYNOTE', 'KEYNOTE_SPEECH', 'CHARLA_MAGISTRAL', 'WORKSHOP', 'TALLER',
  'PANEL', 'PRESENTATION', 'PITCH', 'NETWORKING', 'BREAK', 'CEREMONY',
  'CONFERENCIA', 'MESA_REDONDA', 'FORO', 'SEMINARIO', 'CURSO', 'OTRO', 'OTHER'
);
```

Opción B - Empezar con base de datos limpia:
```bash
rm -f prisma/db/custom.db
bun run db:push
bun run db:seed
```
